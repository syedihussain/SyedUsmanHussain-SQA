SQA AI Agent

An agent that scans a website and generates test cases with AI. Built in C# with Selenium and MSTest.

The lesson so far: the AI is only as good as what it can see. If the page information is incomplete, the generated test cases are incomplete, and no prompt can fix that. So I'm reworking the discovery part:

  • Reads the whole menu, including collapsed sections and hidden sidebar links
  • Names pages from menu text and headings instead of the browser title
  • Detects icon-only buttons (view, edit, add) from their class, title and aria-label
  • Lets the user pick a page by name from a searchable list
  • Clicks only Create, Update and View controls, never Delete or Save
